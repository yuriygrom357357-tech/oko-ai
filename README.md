# ОКО-ШІ · EYE-AI

Аналіз відео з БпЛА у браузері: підсвічує **піхоту** (червоний), **техніку** (жовтий), **дрони в небі** (зелений) з відсотком впевненості.
Працює офлайн після першого відкриття, ШІ виконується на пристрої (дані нікуди не надсилаються).

- Джерела: відеозапис, екран (вікно пульта), камера / HDMI-грабер
- Журнал виявлень, запис відео з розміткою, знімки
- «Статистика» за 3 доби: підсумок, активність по годинах, фото-підтвердження, звіт

Прототип. Рішення приймає оператор.
